That is not an approval.** The complete register — defaults, classification (preserved existing rule / temporary technical safeguard / documented risk), whether confirmation is required, and the switch — is in `MANAGEMENT_DEFAULTS_REGISTER.md`; `php artisan ssi:defaults-report --check` verifies the live configuration against it.
